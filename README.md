# Saldo Safely

Aplicação independente de finanças pessoais para registrar, acompanhar e analisar receitas, despesas, cartões, orçamentos e aportes.

## Arquitetura planejada

- Frontend: React + TypeScript + Vite
- Gráficos: Recharts
- Banco/Auth: Supabase em organização própria `fast_finance`
- Deploy: Vercel independente
- Entrada conversacional: WhatsApp Business Platform
- Repositório: `lucasasilvavps22-tech/saldo-safely`

## MVP

A branch `feature/finance-mvp` contém a primeira versão do dashboard com:
- indicadores mensais;
- despesas por categoria com detalhamento;
- evolução financeira;
- orçamentos;
- transações;
- cartões e contas;
- categorias;
- protótipo do Assistente WhatsApp.

Nenhum recurso ou banco do CoreFlow é compartilhado com este projeto.
